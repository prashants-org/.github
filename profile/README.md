Websites for a family of businesses — Prakhar Technology, Unnati Ladder and Streetwear Retail — all hosted on GitHub Pages.

## 🌐 Projects

| Project | What it is | Live site | Stack |
|---|---|---|---|
| [**prakhartech**](https://github.com/prashants-org/prakhartech) | Prakhar Technology, a Pune-based company: GPS vehicle tracking, Elide Fire Ball fire safety, and industrial & office supplies | [prakhartech.com](https://www.prakhartech.com) | React 19, Vite, React Router, Vitest, Playwright |
| [**unnatiladders**](https://github.com/prashants-org/unnatiladders) | Unnati Ladder, *"Growing Together"*: a franchise and business consultancy | [unnatiladder.com](https://unnatiladder.com) | Static HTML/CSS (archived WordPress site) |
| [**streetwearretail**](https://github.com/prashants-org/streetwearretail) | Streetwear Retail: "coming soon" landing page for a streetwear store | [streetwearretail.com](https://streetwearretail.com) | HTML, CSS, JavaScript |

### Prakhar Technology at a glance

- 🛰️ **GPS tracking**: vehicle and fleet tracking, personal trackers, security and tracking software
- 🔥 **Elide Fire Ball**: fire extinguishing ball, with product overview, FAQ, warranty and safety information
- 🗂️ **Stationery & supplies**: office, computer, housekeeping, packaging and safety products, plus corporate gifts
- ⚙️ **Engineering**: CI runs ESLint, unit tests and Playwright end-to-end tests; deploys go to GitHub Pages through GitHub Actions

## 🚀 Working on these repos

```bash
# Prakhar Technology (React + Vite)
git clone https://github.com/prashants-org/prakhartech.git
cd prakhartech && npm install && npm run dev

# Unnati Ladder / Streetwear Retail (static): open index.html in a browser
git clone https://github.com/prashants-org/streetwearretail.git
```

Each repo has a `CNAME` file for its custom domain and is served by **GitHub Pages**.
